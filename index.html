Aug 2026 – Aug 2026

Blue-green deployment on GCP with Terraform

  • Described a blue-green deployment on Google Cloud entirely as code with Terraform: two identical environments (blue and green), each with its own instance template and regional managed instance group of 2 VMs.
  • Put both environments behind one global external HTTP load balancer, built from a URL map, a target HTTP proxy and a forwarding rule.
  • Controlled traffic with weighted backend services: blue_weight and green_weight variables decide what percentage of requests goes to each environment, so a release can be switched over all at once or shifted gradually and rolled back by changing one number.
  • Added an HTTP health check so the load balancer sends traffic only to healthy instances.
  • Provisioned the VMs with startup scripts that install and start Nginx and serve a page identifying the environment.
  • Exposed the load balancer IP and the names of both environments as outputs.

Aug 2026 – Sep 2026

Kubernetes Practical Task

  • Built a Docker image for a Flask application, with a Dockerfile that passes the Hadolint linter with no errors or warnings, and published it to a private DockerHub repository.
  • Verified the app locally with Docker Compose: Flask application and MongoDB containers wired together through environment variables.
  • Wrote the Kubernetes manifest for a three-tier layout: NGINX Ingress as the presentation layer, a Flask Deployment and Service as the application layer, and a MongoDB StatefulSet as the data layer.
  • Configured liveness and readiness probes, the Recreate deployment strategy, CPU and memory requests and limits, and an init container that waits for MongoDB to start.
  • Moved configuration and credentials out of the manifest into a ConfigMap and Kubernetes Secrets, including an image pull secret for the private registry.
  • Ran everything in a personal namespace on local Minikube, with Role and RoleBinding limiting access to that namespace only.
